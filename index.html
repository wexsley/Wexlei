A cola mental do NOX

Não é para colar na prova, criatura. É para deixar as regras organizadas na cabeça.

As regras que resolvem a maior parte dos exercícios

RegraValor comumExemplos
Substância simplesNOX = 0O₂, H₂, Fe, S₈
Íon monoatômicoNOX = carga do íonNa⁺ = +1; S²⁻ = −2
Íon ou molécula compostaSoma dos NOX = carga totalH₂O: soma = 0; SO₄²⁻: soma = −2
Metais alcalinos (grupo 1)+1NaCl, K₂O
Metais alcalino-terrosos (grupo 2)+2MgO, CaCl₂
OxigênioGeralmente −2Exceção: peróxidos, −1; em OF₂, +2
HidrogênioGeralmente +1Em hidretos metálicos, −1 (ex.: NaH)
Flúor−1Em seus compostos
OxidaçãoNOX aumenta+2 → +3
ReduçãoNOX diminui+5 → +2

Exemplo resolvido: NOX do enxofre no H₂SO₄

O hidrogênio costuma valer +1 e o oxigênio, −2. Como a molécula é neutra, a soma deve dar zero.

2(+1) + x + 4(−2) = 0Some os valores conhecidos e deixe x sozinho.
2 + x − 8 = 0 → x = +6Resposta: o NOX do enxofre é +6.

Checklist para responder oralmente

1. Diga a regra usada. 2. Mostre os valores conhecidos. 3. Explique a soma da carga. 4. Conclua com o NOX e o sinal. Se esquecer, volte à regra antes de chutar qualquer número.
